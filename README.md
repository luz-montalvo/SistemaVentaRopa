# SistemaVentaRopa

## Descripción

Sistema de gestión y venta de prendas de vestir desarrollado como proyecto académico para la Universidad Peruana Unión (UPEU).

El sistema permite registrar, visualizar, buscar, editar y eliminar prendas de vestir mediante una interfaz gráfica de escritorio.

## Tecnologías utilizadas

* Java
* JavaFX
* Maven
* Lombok
* Git y GitHub
* ArrayList
* Programación Orientada a Objetos (POO)

## Funcionalidades

* Registro de prendas.
* Listado de prendas.
* Búsqueda de prendas por nombre.
* Edición de prendas.
* Eliminación de prendas.
* Validación de datos.
* Interfaz gráfica con JavaFX.

## Datos de la prenda

Cada prenda contiene:

* ID
* Nombre
* Categoría
* Talla
* Color
* Precio
* Stock

## Estructura del proyecto

El proyecto está organizado en:

* `model` — modelos del sistema.
* `repository` — manejo de datos mediante ArrayList.
* `service` — lógica del sistema.
* `controller` — controladores de JavaFX.
* `view` — interfaces FXML.
* `config` — configuración del proyecto.

## Ejecución

Para ejecutar el proyecto mediante Maven:

```bash
mvn clean javafx:run
```
